# Скрипт для расчёта и визуализации банкролла PokerOK

**Bankroll-Tracker** `bankroll.py` — это консольная Python-утилита для анализа и визуализации банкролла игроков PokerOK / GGPoker. Скрипт читает CSV-файлы с результатами сессий (кэш, SNG, MTT), рассчитывает ключевые покерные метрики и строит график кумулятивной прибыли.

---

## 🚀 Основные возможности

- 📈 Расчёт ключевых показателей:
  - Общая прибыль и EV-прибыль  
  - ROI%, ITM%, bb/100  
  - Стандартное отклонение и дисперсия  
- 🧮 Поддержка кэша, SNG и MTT форматов  
- 🔍 Фильтрация по дате, типу игры и сайту (PokerOK, GGPoker)  
- 💱 Конвертация валют с ручным вводом курсов (`--fx`)  
- 🧾 Группировка по месяцам, неделям, дням, форматам или типу игры  
- 📊 Экспорт отчёта в CSV  
- 🖼️ Генерация PNG-графика кумулятивной прибыли  
- 💬 Цветной консольный отчёт (с отключением `--no-color`)  
- ⚙️ Работа без сторонних зависимостей (только стандартная библиотека и `matplotlib`)

## 📂 Формат входных данных

Скрипт принимает CSV (или TSV) файлы с колонками:

| Поле            | Тип     | Описание                                                         |
| --------------- | ------- | ---------------------------------------------------------------- |
| `date`          | `str`   | Дата и время сессии (формат `YYYY-MM-DD` или `YYYY-MM-DD HH:MM`) |
| `site`          | `str`   | Название рума (`GGPoker`, `PokerOK` и т.п.)                      |
| `game`          | `str`   | Тип игры (`cash`, `sng`, `mtt`)                                  |
| `format`        | `str`   | Формат/лимит (`NL50 6max`, `$11 PKO`, `SNG 9max`)                |
| `buyin`         | `float` | Бай-ин одной записи                                              |
| `cashout`       | `float` | Кэш-аут / приз                                                   |
| `currency`      | `str`   | Валюта (`USD`, `EUR` и т.д.)                                     |
| `hands`         | `int`   | Количество раздач (для кэша)                                     |
| `stake_bb`      | `float` | Размер большого блайнда                                          |
| `rake`          | `float` | Рейк (если доступен)                                             |
| `rebuys`        | `float` | Сумма или количество ребаев                                      |
| `addons`        | `float` | Сумма или количество аддонов                                     |
| `ev_allin_diff` | `float` | EV-дельта по ол-инам (если доступна)                             |
| `notes`         | `str`   | Комментарий / заметка (опционально)                              |

## ⚙️ Использование

### Базовый запуск

```bash
python bankroll.py --data sessions_pokerok.csv
```

### Отчёт за определённый период

```bash
python bankroll.py --data sessions_pokerok.csv --site GGPoker --from 2025-10-01 --to 2025-10-31
```

### С построением графика

```bash
python bankroll.py --data sessions_pokerok.csv --plot profit_october.png
```

### Группировка по месяцам и экспорт в CSV

```bash
python bankroll.py --data all_sessions.csv --group-by month --export summary.csv
```

### Конвертация валют

```bash
python bankroll.py --data sessions.csv --currency USD --fx "EUR:1.08,USD:1,BRL:0.18"
```

### Интерпретация ребаев как количества

```bash
python bankroll.py --data sessions.csv --rebuys-are-counts
```

## 📈 Вычисляемые метрики

| Метрика       | Описание                                   |
| ------------- | ------------------------------------------ |
| **Profit**    | Кэш-аут − (бай-ин + ребаи + аддоны + рейк) |
| **EV Profit** | Profit + EV-дельта по ол-инам              |
| **ROI%**      | `(Profit / Total Buyin) × 100`             |
| **ITM%**      | `(Выигрышные записи / Все записи) × 100`   |
| **bb/100**    | `(Profit / BB) / (hands / 100)`            |
| **StdDev**    | Стандартное отклонение профита по сессиям  |

---

## 🧠 Дополнительные опции

| Аргумент              | Назначение                                                    |
| --------------------- | ------------------------------------------------------------- |
| `--group-by`          | Группировка отчёта (`month`, `week`, `day`, `format`, `game`) |
| `--export`            | Сохранить агрегированный отчёт в CSV                          |
| `--no-color`          | Отключить цветной вывод                                       |
| `--quiet`             | Минимальный вывод                                             |
| `--verbose`           | Подробные логи                                                |
| `--rebuys-are-counts` | Трактовать `rebuys`/`addons` как количество, а не сумму       |
